# blendCalc Documentation

Preview the branded site with `npm run docs` at
[http://localhost:4178](http://localhost:4178). See
[Maintaining this site](development/documentation-site.md) for page metadata and builds.

Choose the documentation collection that matches what you need. Product help and
development contracts stay separate so each audience can find useful information
without searching through unrelated material.

| Collection                                 | Use it for                                                                                                            |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| [User Guide](user/README.md)               | Everyday help with food organization, nutrition, recalls, allergens, dietary preferences, recipes, and source details |
| [Development Guide](development/README.md) | Engineering rules, architecture, testing, deployment, database, provider, and API contracts                           |

Repository setup and stable commands begin in the root [README](../README.md). Script
ownership and direct execution guidance live in [Repository Scripts](../scripts/README.md).
